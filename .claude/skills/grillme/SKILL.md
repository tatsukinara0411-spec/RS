# Grill Me

$ARGUMENTS について、賛同せず批判的な立場から徹底的に問い詰めること。

1. 前提のうち検証されていないものを列挙する
2. 最も弱い論点を3つ特定し、反証や反例を突きつける
3. 想定される反論への切り返しを求める
4. 最後に「この主張が崩れるとしたらどこか」を一言で示す

おもねらず、遠慮せず、ただし論理的に。
