# 社内ワールドカップTOTO 2026

## 全体の流れ

```
①胴元がスプシをセットアップ → ②参加者がエントリー → ③試合結果を入力 → ④自動集計でランキング更新
```

---

## セットアップ手順

### 【スプレッドシート版】（推奨・即運用可）

1. [Googleスプレッドシート](https://sheets.google.com) を新規作成
2. 「拡張機能」→「Apps Script」を開く
3. `spreadsheet_setup.gs` の内容を全てコピペして保存
4. 「実行」→`onOpen` を実行（権限を許可）
5. スプレッドシートに戻ると「⚽ TOTO管理」メニューが出現
6. 「🔧 初回セットアップ（シート作成）」をクリック
7. 4つのシートが自動生成される

### 【HTML可視化ページ版】（見栄えを良くしたい場合）

1. `data.js` の `PARTICIPANTS` に参加者データを入力
2. `data.js` の `MATCHES` に試合結果を都度入力
3. GitHub Pages で公開（リポジトリの Settings → Pages → Source: main branch / toto フォルダ）
4. URLを社内に共有

## 各シートの説明

| シート名 | 誰が使う | 用途 |
|---------|---------|------|
| **エントリー** | 参加者 | 各試合の勝者予想を入力 |
| **オッズ** | 胴元 | チームごとのオッズ倍率を設定 |
| **結果入力** | 胴元 | 実際の試合結果（スコア）を入力 |
| **ランキング** | 全員 | 自動集計されたポイントランキングを閲覧 |

---

## ポイント計算ルール

| ラウンド | 基本点 |
|---------|--------|
| R32 | 1pt |
| R16 | 2pt |
| 準々決勝 | 4pt |
| 準決勝 | 8pt |
| 決勝 | 16pt |

**獲得ポイント = 基本点 × 勝者のオッズ倍率**

例：R16でブラジル（オッズ4.5倍）が勝つと予想して的中 → 2 × 4.5 = **9pt**

---

## 賞金配分

- 賞金プール = 参加費合計 × 80%（胴元が20%取り分）
- 1位: 50% / 2位: 30% / 3位: 20%

---

## カスタマイズ

`data.js`（HTML版）または `spreadsheet_setup.gs`（スプシ版）の冒頭にある設定エリアを編集：

- `entryFee`: 参加費
- `houseEdge`: 胴元取り分
- `ODDS`: チームごとのオッズ倍率
- `MATCHES_GAS`: 対戦カード（実際の組み合わせ確定後に更新）
