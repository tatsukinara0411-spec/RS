# テレアポリード自動収集システム

テレアポ部隊向けに、求人サイト3社から毎週300件の企業リストを自動収集し、Googleスプレッドシートへ書き込むシステム。

## 概要

| 項目 | 内容 |
|---|---|
| 収集サイト | マイナビバイト / enゲージ / 求人BOX |
| 件数 | 週300件（各サイト100件） |
| エリア | 東京都内23区 |
| 業種 | 警備 / 運輸 / 外食 |
| 実行タイミング | 毎週月曜日 8:00 JST（GitHub Actions） |
| 出力先 | Googleスプレッドシート |

## スプレッドシートの列

| 会社名 | 住所 | 電話番号 | 業種 | ソース | 収集日時 |

## セットアップ

→ [SETUP.md](./SETUP.md) を参照

## 手動実行

GitHub の「Actions」タブ → 「テレアポリード 週次収集」→「Run workflow」

## 求人原稿 応募率診断ツール（MVP）

`tools/job_diagnosis/index.html` をブラウザで開くと、求人原稿の応募率予測スコアと改善ポイントを診断できる。サーバー不要、Vercel等にそのままデプロイ可能。詳細は [docs/roadmap_2026-06.md](./docs/roadmap_2026-06.md) を参照。
