こんな流れで実行されます

月曜日の朝、裏側でこんな処理が自動で動いています

⏰

毎週月曜8:00 に自動起動 GitHub Actions

タイマーが発動し、プログラムが入っているサーバー（GitHub）から最新のコードを取り出して、処理を開始します。

🌐

3つの求人サイトを同時に巡回 Playwright

目に見えないブラウザ（Chrome）が自動で起動し、マイナビバイト・enゲージ・求人BOXの3サイトを同時に開いて、東京都内の求人情報（警備・ドライバー・飲食）を読み取ります。

📥 取得数：3サイト合計 約576件
🔍

重複チェックで絞り込み SQLite

「先週も同じ会社が載っていた」というケースを自動で除外します。会社名＋住所を組み合わせた識別子（フィンガープリント）を記録しておき、以前に収集済みなら除外。

🗑 重複除外後：約280〜300件に絞り込み
📞

電話番号・住所を2段階で補完 Google Maps API

求人サイトに電話番号が載っていない会社に対し、GoogleマップAPIに自動で問い合わせ。会社名＋住所を送ると、電話番号と番地付き住所が返ってきます。

📞 2026-W23タブ実績：442件中 365件（82%）補填成功
📊

スプレッドシートへ自動書き込み Google Sheets

その週の日付名（例：2026-W24）のタブが自動作成され、会社名・住所・電話番号・業種・収集日時が書き込まれます。担当者はスプレッドシートを開くだけでOK。

✅ 完了：月曜朝には新鮮なリストが届いています
3

使ったアプリケーションはこれです

それぞれの役割と「身近なもので例えると？」

🤖
Claude Code
AIエンジニア
このシステムのプログラムを書いたAI。日本語で「こんな機能がほしい」と伝えると、コードに変換してくれる。
例えると…
設計図を描く建築家。人間の要望を聞いてシステムを設計・構築する。
🐙
GitHub
コード保管庫 ＋ 変更管理
プログラムのコードを保管する場所。変更の履歴が全部残るので、バグが出たときに前の状態に戻せる。シークレット（パスワード類）の安全な保管庫でもある。
例えると…
Googleドライブ＋変更履歴機能。ファイルの全履歴が見える保管庫。
⚙️
GitHub Actions
自動実行スケジューラー
「毎週月曜8時になったら、このプログラムを動かせ」という指示を実行するタイマー付きロボット。手動でも「実行」ボタンを押せば動く。
例えると…
自動炊飯器。「月曜の朝に炊き上がるよう前夜にセット」と同じ仕組み。
🎭
Playwright
ブラウザ自動操作ツール
目に見えない（画面が出ない）Chromeブラウザを自動で操作する道具。人間が手でブラウザを開いてページをスクロールする作業を代わりにやってくれる。
例えると…
URLを渡すだけでネットショッピングを代わりにやってくれるロボット手。
🐍
Python
処理の頭脳（プログラミング言語）
このシステム全体を動かすプログラムの言語。収集・整理・重複チェック・API呼び出し・シート書き込みをすべて指揮している。
例えると…
司令塔。各部門（Playwright・API・スプレッドシート）に指示を出すマネージャー。
🗃️
SQLite
重複チェック用データベース
「以前に収集した会社」を記録しておくメモ帳のようなデータベース。これにより毎週同じ会社がリストに入るのを防ぐ。
例えると…
「もう連絡した会社リスト」が書かれたノート。次回見たとき「あ、これは済み」とわかる。
🗺️
Google Maps API
電話番号・住所の自動調査
Googleマップに掲載されている会社情報をプログラムから検索できる「正式な問い合わせ窓口」。会社名＋住所を送ると電話番号が返ってくる。
例えると…
Googleマップで会社名を検索して電話番号をコピペする作業を、自動でやってくれるロボット。
🔑
Googleサービスアカウント
ロボット用のGoogleアカウント
スプレッドシートに書き込む許可をプログラムに与えるための「ロボット専用のGoogleアカウント」。人間のGmailとは別に作る。
例えると…
会社の公式アカウント。「個人アカウントではなくシステム専用アカウントでログインする」イメージ。
📊
Google スプレッドシート
最終成果物（出力先）
Excelのオンライン版。収集した全リードが毎週新しいタブに書き込まれる。担当者はここを開くだけでテレアポリストが確認できる。
例えると…
毎週月曜の朝に新しい資料が届く「共有フォルダ」。
テレアポリード収集システム 構成説明 ／ カードにカーソルを合わせると詳細が強調表示されます
