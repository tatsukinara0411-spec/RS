🛠 開発・管理レイヤー
🤖
Claude Code
AIアシスタント

Claude Code とは？

Anthropic社が作ったAI（人工知能）。今回このシステムのコード（プログラム）を書いたのはこのAI。人間がやりたいことを日本語で伝えると、プログラムに変換してくれる。

🐙
GitHub
コード保管庫

GitHub とは？

プログラムのコードを保管・管理する場所（クラウド上の引き出し）。変更履歴が全部残るので、バグが出たときに前の状態に戻せる。

  • コードのバージョン管理
  • プルリクエスト（変更の審査）
  • シークレット（パスワード類）の安全な保管
⚙️
GitHub
Actions
自動実行エンジン

GitHub Actions とは？

「毎週月曜8時になったら自動でプログラムを動かす」という指示を実行してくれる仕組み（タイマー付きロボット）。

  • 毎週月曜8:00 JST に自動起動
  • 手動でも「ワークフローを実行」ボタンで起動可能
  • 成功・失敗のログを記録
📥 データ収集レイヤー（求人サイトから自動で情報を読み取る）

マイナビ
バイト
求人サイト

マイナビバイト

大手求人サイト。警備・ドライバー・飲食カテゴリから東京都の求人を最大66件/カテゴリ収集。会社名・住所・業種を取得。

🟢
enゲージ
求人サイト

enゲージ

en Japan運営の求人サイト。同様に3カテゴリ×最大60件を収集。会社名・住所・業種を取得。

🟡
求人BOX
求人サイト

求人BOX

求人ボックス（カカクコム系）。3カテゴリ×最大66件収集。さらに詳細ページも自動で訪問して電話番号・番地付き住所を取得（約30%で成功）。

🔧 処理レイヤー
🎭
Playwright
ブラウザ自動操作

Playwright とは？

目に見えないブラウザ（Chrome）を自動で操作するツール。人間が手でブラウザを開いてスクロールする作業を、プログラムが代わりに自動でやってくれる。

  • 3サイトを同時並列でアクセス
  • ページをスクロールして全情報を取得
  • 求人BOXは詳細ページも自動クリック
🐍
Python
プログラム
処理の頭脳

Python とは？

このシステム全体の「頭脳」となるプログラミング言語。収集・整理・重複チェック・API呼び出し・シートへの書き込みを一括で制御している。

  • 3サイトのデータを束ねる
  • 重複チェック（SQLite）
  • GoogleマップAPIへの問い合わせ
  • スプレッドシートへの書き込み
🗃️
SQLite DB
重複チェック

SQLite とは？

小さなデータベース（メモ帳のような記録帳）。「先週もこの会社を収集した」という記録を残して、同じ会社が毎週重複してリストに入らないようにする。

  • 会社名＋住所のフィンガープリントを保存
  • すでに見た会社は自動でスキップ
🔍 電話番号・住所補完レイヤー
🗺️
Google
Maps API
電話番号・住所検索

Google Maps API とは？

Googleマップに掲載されている会社情報をプログラムから検索できる「正式な窓口」（API）。会社名と住所を伝えると、電話番号と番地付き住所を返してくれる。

  • 求人サイトで電話番号が取れなかった会社を対象
  • 2026-W23タブで442件中365件補填成功（82%）
  • 月$200の無料枠内で収まる

サービスアカウントとは？

Googleスプレッドシートに書き込む許可を得るための「ロボット用のGoogleアカウント」。人間のアカウントではなくプログラム専用のアカウント。

  • Google Cloud Console で発行
  • JSONキーファイルをGitHubのシークレットに登録
  • スプレッドシートに「編集者」として共有する必要あり

出力・最終成果物

Google スプレッドシートとは？

Excelのオンライン版。収集した全リードが毎週新しいタブ（例：2026-W24）に自動で書き込まれる。電話番号・住所・会社名・業種が入った状態で届く。

  • 毎週月曜に新しいタブが自動作成
  • 会社名・住所・電話番号・業種・収集日時
  • 目標：約300件/週
